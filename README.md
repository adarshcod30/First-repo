# First-repo

The first repository I ever created, on 13 June 2025.

It contains a README and an empty `index.html`. That is the whole thing, and
it is kept public on purpose. Every project on this account is built on the
claim that I publish what a sceptical reader can check, and quietly deleting
the beginning would be the cheapest kind of dishonesty.

If you are looking for the work, start at
[my profile](https://github.com/adarshcod30) or the
[project index](https://github.com/adarshcod30/adarshcod30/blob/main/PROJECTS.md).

## What I was learning here

How to create a repository, make a commit and push it. Nothing else.
